# 基于FPGA的心电信号硬件流水线预处理与波形可视化
FPGA创新设计竞赛参赛项目

## ✨ 项目简介
本项目在FPGA硬件端完成心电信号流水线处理，包含FIR滤波、基线校正、硬件R波检测、心率计算，最终通过UART串口上传至电脑，使用VOFA+软件实时绘制心电波形、显示心率。区别于市面MCU采集方案，全部信号处理逻辑在FPGA硬件流水线实现。

## 📌 核心模块
- AD8232心电采集模块
- FIR滤波+基线校正硬件流水线模块
- R波检测、心率计算模块
- UART串口发送驱动模块（上传数据给VOFA+上位机）

## 🛠️ 硬件平台
开发板：依元素 EGO1（Xilinx Artix-7，XC7A35T-1CSG324C）
外设：AD8232心电采集模块、电极片

## 📂 仓库文件结构
- src/ Verilog源代码
- xdc/ 引脚约束文件
- doc/ 框图、测试图、说明文档

## 📝 备注
本工程为竞赛自研实现，所有算法在FPGA硬件流水线运行，不依赖MCU做信号运算。
